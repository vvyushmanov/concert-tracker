# Quick Start Guide

## Prerequisites

- Docker and Docker Compose
- Last.fm API key ([get here](https://www.last.fm/api/account/create))

## Setup (3 steps)

### 1. Create `.env` File

```bash
cp .env.example .env
```

Edit `.env` - **only these fields are required:**

```env
# MySQL credentials
MYSQL_ROOT_PASSWORD=your_password
MYSQL_USER=concertuser
MYSQL_PASSWORD=your_password

# Last.fm API
LASTFM_API_KEY=your_api_key
LASTFM_USER=your_username
```

**Optional:**
- `FANART_API_KEY` - For artist images ([get here](https://fanart.tv/get-an-api-key/))
- `COUNTRY_CODES` - Countries to search (default: `ge,tr,fr,de,es`)
- `MIN_PLAYCOUNT` - Minimum artist playcount (default: `40`)

**Note:** `DATABASE_URL` is auto-generated by docker-compose - don't set it manually

### 2. Start the Application

```bash
docker compose -f docker-compose.dev.yml up
```

Wait for: `✓ Startup complete! Starting dev server...`

**First run:** ~2-3 minutes | **Subsequent:** ~30 seconds

### 3. Open Browser

**http://localhost:3000**

## What Happens Automatically

1. Switch Prisma schema (MySQL/SQLite)
2. Install dependencies
3. Generate Prisma client
4. Wait for MySQL (skipped for SQLite)
5. Create database tables (only if missing)
6. Start dev server

**Safe:** Never deletes data, checks if tables exist first

## Troubleshooting

**Permission errors on `./data/db/`:**
```bash
docker compose -f docker-compose.dev.yml down
sudo rm -rf ./data/db/*
docker compose -f docker-compose.dev.yml up
```

**Port already in use:**
```bash
sudo lsof -i :3000  # or :3306
```

**Startup hangs:** Check `.env` has correct `DB_TYPE` (mysql or sqlite)

**"Schema already exists":** Normal - prevents data loss on restart

## Usage

- **Fetch concerts:** http://localhost:3000/scanner
- **Browse:** Main page, artists, calendar views
- **Stop:** `docker compose -f docker-compose.dev.yml down`
- **Hot reload:** Edit files in `concert-tracker/` - changes apply instantly

## Switch Database

Edit `.env` set `DB_TYPE=sqlite` or `DB_TYPE=mysql`, then:
```bash
docker compose -f docker-compose.dev.yml restart web
```

## Production

```bash
docker compose -f docker-compose.yml up -d
```

Set strong passwords in `.env` and backup `./data/db/` regularly.
